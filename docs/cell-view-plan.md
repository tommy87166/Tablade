# 下方面板的「檢視」分頁：點一格，在下面看完整的內容（實作計畫）

- 狀態：**實作計畫，尚未實作**（2026-11-20）。
- 範圍：只有前端。預覽表格（`frontend/src/components/PreviewGrid.tsx`）、下方面板（`frontend/src/App.tsx`）、一個新元件與一個小的純函式模組。Python、`bridge.ts` 的 API、Recipe 都不變，不升 `RECIPE_VERSION`。
- 和 docs/custom-expression-plan.md 一起實作。兩份互不相干，各自一個（或幾個）commit；唯一共用的是前端測試的設定（見「測試」）。

## 給實作的人

- 先讀 CLAUDE.md 的「前端規則」。這份計畫和 CLAUDE.md 不一致的地方，以 CLAUDE.md 為準，並回報。
- 每個 commit 都要過 `pytest`、`check_no_data.py --all`、`check_code_policy.py`、`npm --prefix frontend run lint`、`npm --prefix frontend run build` 與前端的測試。
- 做完後把最上面的狀態改成「已實作」，並寫下和計畫不同的地方。

## 問題

預覽表格的每一格只顯示一行，放不下的部分用「…」蓋掉。

- 資料是完整的：Python 的 `Session.rows()` 把每一格的值原樣送到畫面，沒有截短（只有 JSON 表示不了的值會改成文字，和長度無關）。截短是畫面顯示時做的（儲存格的 `truncate`）。
- 欄寬自動量，最寬 360 px（`MAX_WIDTH`）；拖曳欄標題的右邊界最寬可以拉到 1,200 px（`RESIZE_MAX`）。再長的文字（例如還沒拆欄的整行）沒辦法在格子裡看完。
- 現在要看完整的內容，只能把滑鼠停在那一格上等提示（儲存格的 `title`）。提示要等、不能選取複製、很長的文字顯示不完，而且看不出前後有沒有空白。

## 已決定（2026-11-20 和維護者確認）

- 下方面板多一個分頁，叫**「檢視」**。
- **點表格裡的一格，完整的內容顯示在「檢視」分頁。**
- **不用滑鼠停留（hover）顯示內容**：拿掉儲存格的提示。

寫計畫時定的（還沒有個別確認，不同意的話改這裡）：

- 點了格子，下方面板會自動切到「檢視」，收合著的話會展開。
- 只有滑鼠左鍵點資料格算；右鍵、行號欄、欄標題不算。
- 換步驟、換階段、預覽重算時清掉選到的格子。
- 「檢視」除了完整的值，還顯示欄名與型別、第幾列、來源檔與行號、文字的長度。
- 行號欄上「滑鼠停留顯示來源檔」的提示也一起拿掉，來源檔改在「檢視」顯示；欄標題的提示（型別）留著。
- 英文叫 Inspect。
- 不做複製按鈕、方向鍵移動、整列檢視（「不做的事」）。

## 做法

### 點一格

- 在資料格上按滑鼠左鍵：那一格變成「選到的格子」，表格上用外框標出來；下方面板切到「檢視」分頁，面板收合著的話順便展開（現有的 `openBottomTab`）。
- 同一時間只有一格被選到。點另一格就換過去。
- 最左邊的行號欄、欄標題不能選（欄標題的拖曳調寬、雙擊照舊）。還沒載入的列（顯示「…」的格子）不能選。
- 按右鍵照舊開右鍵選單，不改變選到的格子。
- 在格子裡拖曳選取文字再放開，也算點了那一格（瀏覽器在同一個元素上放開就會送出 click）；不用特別處理。
- 實作：在包住所有列的那個 `<div>` 上加 `onClick`（和現在的 `onContextMenu` 同一個地方、同樣用 `closest('[data-col]')` 找出是哪一格），不要每一格各掛一個事件。

### 什麼時候清掉選到的格子

- 換步驟、換階段、預覽的內容變了（表格現在會丟掉快取、捲回最上面的那些情況：`step` 或 `resetKey` 變了）：清掉，「檢視」分頁回到提示文字。
- 系統欄位被藏起來（「顯示系統欄位」關掉）而選到的正好是系統欄位：清掉。
- 單純捲動、調欄寬、切到下方面板的其他分頁再切回來：不清掉。選到的那一列捲出畫面再捲回來，外框還在。
- 「檢視」分頁顯示的是**點的當下那一格的值**（存一份下來），不會因為那一頁的快取被換掉而消失。

### 「檢視」分頁的內容

沒有選到格子時，只有一行提示：「點表格裡的一格，這裡會顯示完整的內容」。

選到格子時，由上到下：

1. **一行位置與資訊**（次要的文字色，放不下就換行）：
   - 欄名與型別：`品名（文字）`。型別用畫面狀態裡那一欄的 `dtype`（和欄標題的提示同一個來源）。
   - 第幾列：`第 1,234 列`（整個結果的第幾列，從 1 起）。
   - 來源：`來源檔［工作表］:行號`，寫法和警告分頁的位置一樣（`App.tsx` 的 `place`；把組字串的部分抽成可以共用的函式）。來源檔、工作表、行號從那一列的 `__source_file`、`__sheet`、`__line_no` 讀（系統欄位沒有顯示在表格上時，資料裡還是有）；那一步之後沒有這些欄位（例如群組彙總之後）就不寫這一段。
   - 文字的長度：`共 86 個字`（只有值是文字時；用字元數，不是位元組數：`[...value].length`）。
2. **完整的值**：
   - 用等寬字、保留所有空白與換行、自動換行（`white-space: pre-wrap; overflow-wrap: anywhere`），放在一個有底色與邊框的框裡：前後的空白看得出來（框的邊界就是值的邊界）。
   - 文字可以用滑鼠選取、複製（`select-text`）。
   - 內容比面板高時，面板自己捲動。
   - 空值顯示斜體的 `null`（和表格一樣），旁邊註明「空值」；空字串顯示「（空字串）」，用次要的文字色。兩種都不放進上面那個框，避免看起來像是值本身。
   - 數字、日期、是／否：照表格顯示的文字（`String(value)`）。

分頁按鈕：圖示加「檢視」（英文 `Inspect`），放在「型別」的右邊。按鈕上不寫數量或狀態。

### 拿掉滑鼠停留的提示

- 資料格的 `title`（`PreviewGrid.tsx` 裡 `title={value === null ? undefined : String(value)}`）：拿掉。
- 行號欄的 `title`（滑鼠停在行號上顯示來源檔）：拿掉。來源檔改在「檢視」分頁的那一行顯示（點那一列的任何一格就看得到）。
- **不動的**：欄標題的提示（欄名與型別）、調欄寬把手的提示、資料 pane 標題列那幾個徽章的提示、右鍵選單最上面那一行。這些不是儲存格的內容。

## 實作

1. **純函式（新檔 `frontend/src/lib/cell.ts`，沒有任何 import）**
   - `cellView(columns, row, rowIndex, column, dtype)`：回傳「檢視」分頁要顯示的那一份資料（欄名、型別、第幾列、值、來源檔、工作表、行號、字元數）；`column` 不在 `columns` 裡時回傳 `null`。
   - `sourceText(file, sheet, line, …)`：組「來源檔［工作表］:行號」的字串；`App.tsx` 的 `place` 改成用它（輸出要和現在完全一樣）。中英文的差別（工作表的括號）由呼叫的地方傳進來，這個檔不 import `tr`，測試才能直接跑。
2. **`PreviewGrid.tsx`**
   - 新的 prop：`onSelectCell?: (cell: CellView | null) => void`。
   - 內部的狀態：選到的位置（第幾列、欄名）。點一格時設定並呼叫 `onSelectCell(cellView(…))`；上面「什麼時候清掉」的情況發生時清掉並呼叫 `onSelectCell(null)`。
   - 畫每一格時，位置和選到的相同就加外框（`ring-2 ring-inset ring-primary` 這類現有的顏色，淺色與深色都要看得清楚；外框不能改變格子的大小）。
   - 拿掉上面說的兩個 `title`。
3. **新元件 `frontend/src/components/CellView.tsx`**：畫「檢視」分頁的內容。只吃一個 `CellView | null`，不呼叫 API。
4. **`App.tsx`**
   - `bottomTab` 的型別加 `'view'`；多一個 `BottomTab` 按鈕；內容區多一個分支。
   - 一個狀態存選到的那一格（`CellView | null`）；`PreviewGrid` 的 `onSelectCell` 收到不是 `null` 的值時存起來並 `openBottomTab('view')`，收到 `null` 時只清掉（不切分頁）。
   - 表格沒有畫出來的時候（沒有資料、那一步算不出來）也要清掉，不要留著上一次的內容。
5. **文字**：全部用 `tr('中文', 'English')`，不能在模組最上層用 `tr()`。`docs/i18n-plan.md` 的用語表加「檢視／Inspect」。
6. **文件**：DESIGN.md §16.6 的「中間：預覽表格」補一句（點一格在「檢視」分頁看完整的內容，不用滑鼠停留）、「下方：兩個分頁」改成三個並說明「檢視」。README 兩份有提到下方面板的分頁或滑鼠停留看內容的地方一起改（先搜尋；沒有就不用改）。

不用改的：`api.py`、`session.py`、`bridge.ts` 的 `TabladeApi`、`mock.ts`、`scripts/gen_frontend_dev_data.py`。

## 測試

### 1. 純函式（`node --test`）

`frontend/tests/cell.test.ts`，用 `node:test` 與 `node:assert`。測試的設定（`frontend/tests/` 資料夾、`package.json` 的 `"test": "node --test tests/"`、CI 的 `npm test`、CLAUDE.md 的指令）和 docs/custom-expression-plan.md 的第 4 步是同一份：先做的那一邊把設定加好，後做的只加測試檔。不加任何依賴。

- `cellView`：
  - 一般的文字格：欄名、型別、第幾列（傳進去的是從 0 起，顯示的是加 1）、值、字元數都對。
  - 來源：有 `__source_file` 與 `__line_no`；另外有 `__sheet`；三個都沒有（回傳的來源是 `null`）；只有其中一個。
  - 值是 `null`、空字串、只有空白、有換行與 Tab、數字、`true`／`false`、很長的文字（十萬個字）。
  - 字元數：中文、表情符號（一個表情符號算一個字）、空字串是 0；值不是文字時沒有字元數。
  - `column` 不在 `columns` 裡：回傳 `null`。
- `sourceText`：有沒有工作表；和 `App.tsx` 原本的 `place` 對同樣的輸入產生同樣的字串（把原本的幾種情況各寫一個例子：一般、有工作表、有階段、有「原始」的來源）。

- `uv run pytest`：`tests/test_app.py`（前端原始碼沒有 `innerHTML`、`dangerouslySetInnerHTML`、`fetch`、`eval`；`bridge.ts` 與 `api.py` 一致）、`tests/test_i18n.py`（新的文字都是 `tr()`、沒有在模組最上層用）。
- `scripts/check_no_data.py --all`、`scripts/check_code_policy.py`、`ruff`。

另外加一個 Python 的測試（放在 `tests/test_app.py`）：`PreviewGrid.tsx` 的資料格與行號格沒有 `title=` 屬性（搜尋原始碼裡那兩段），避免之後有人把滑鼠停留的提示加回來。

### 3. 畫面實際操作

用瀏覽器的開發模式（先 `uv run python scripts/gen_frontend_dev_data.py`，再 `npm --prefix frontend run dev`）與真正的視窗（`TABLADE_DEV_URL=http://localhost:5173 uv run tablade`）各走一遍，淺色與深色都看：

- **點一格**：那一格有外框；下方面板切到「檢視」；內容是那一格完整的值。下方面板收合著時會展開。
- **很長的文字**：選還沒拆欄的階段（每一列是一整行），點一格：整行都看得到、會自動換行、面板可以捲動；表格上那一格還是只有一行。
- **空白**：值的前後有空白、中間有連續的空白、有 Tab 時看得出來；字元數有把空白算進去。
- **空值與空字串**：分別顯示 `null`（空值）與「（空字串）」，兩種看得出差別。
- **數字、日期、是／否**的格子：顯示的文字和表格上一樣。
- **位置那一行**：欄名、型別、第幾列、來源檔與行號都對（拿表格上的行號對）；讀 Excel 全部工作表時有工作表；「顯示系統欄位」關著時來源還是有；群組彙總之後的步驟沒有來源那一段。
- **第幾列**：捲到很後面（例如第 5,000 列）點一格，數字對；超過 50 萬列的結果切到第二段再點，數字是整個結果的第幾列。
- **選取與複製**：「檢視」裡的文字可以用滑鼠選取，Ctrl／Cmd+C 複製後貼到別的地方是完整的。
- **換格子**：點另一格，外框與內容都換過去。
- **清掉**：換步驟、換階段、改參數讓預覽重算、重新載入資料之後，外框不見、「檢視」回到提示文字；那一步算不出來（表格換成原因與按鈕）時也是。
- **不清掉**：捲動、調欄寬、切到「警告」或「型別」再切回「檢視」，內容還在；捲走再捲回來外框還在。
- **沒有提示**：滑鼠停在資料格與行號上，等兩秒，沒有跳出提示。欄標題的提示還在。
- **其他功能沒有壞**：右鍵選單照舊（而且不會改變選到的格子）；拖曳欄標題調寬、雙擊回到自動寬度；點警告跳到那一列；「型別」分頁照舊。
- **鍵盤**：用 Tab 可以移到「檢視」的分頁按鈕並按下去。
- 畫面的語言切成英文：分頁叫 Inspect，提示文字與位置那一行是英文。
- 視窗縮窄、下方面板拉到很矮時不會跑版。

## 不做的事

- 不做「複製」按鈕：文字可以直接選取複製。（視窗的頁面是用字串載入的，瀏覽器的剪貼簿 API 在這種頁面不一定能用；要做的話另外開一項。）
- 不做用方向鍵在格子之間移動。
- 不做「整列檢視」（點行號把那一列的每一欄列出來）。
- 不在「檢視」裡編輯值：預覽的資料是算出來的，要改就加步驟。
- 不改欄寬的上限（360 px、1,200 px）與儲存格只顯示一行的做法。
- 不把選到的格子存到 Python 或 Recipe：它只是這次開著的畫面上的狀態，和捲動的位置一樣。
- 換步驟後不保留選到的格子（表格本來就會捲回最上面）；要看同一格在另一步的樣子，再點一次。
